# 常见失败与修复

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 数字停在 127 或 128.0001 | 终帧仍在插值 / 浮点 | 用 countValue：p≥1 直接返回目标值 |
| 计数时宽度跳动 | 非等宽数字 | tabular-nums；里程表固定列数 |
| 出现 00:60 | 把时间当十进制 | 用 ClockRoll / formatClock（混合进制） |
| 倒计时最后一帧不对 | 时长覆盖到合成末帧之外 | 让 start+dur ≤ 最后一帧 |
| 渲染闪烁 / 跳帧画面不同 | CSS transition、随机数、累加状态 | 全部改为 f(frame)；固定 seed |
| 字压到字幕 | 主画面版位过低 | 主画面 y ≤ 1500；分拍 |
| 卡片搬空后成了空框 | 源头没有交代 | 留"已移入"残影或让源卡片收起 |
| 角标和标题重叠 | 标题换行后变高 | 角标行下移，或标题缩放后单行 |
| 渲染时报 typescript.sys 未定义 | 环境中 typescript 构建不完整 | 用 scripts/webpack-override.mjs（已内置） |
| 等待中的事项突然上下漂、互相叠字 | 弧线被套在"停留段"上 | 弧线只给真正的搬运段（≥120px）或在目标 key 上写 `arc` |
| 搬运途中压到别的字 | 层级与外观没变 | 被搬运时变成不透明小卡片（Lifted）、层级置顶，落地前淡回原样 |
