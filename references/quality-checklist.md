# 验收清单

## 自动门禁
- [ ] `quick_validate.py`：结构、frontmatter、版本一致、openai.yaml、UTF-8、无临时文件、seek-safe 静态扫描、语义落地。
- [ ] `motion_logic_test.ts`：计数终值精确、不越过目标、里程表进位、时钟进位/借位、hh:mm 跨日、搬运落位、乱序求值一致。
- [ ] `render_check.mjs`：`checks` 中每个帧的真实显示值等于期望；随机帧正序 / 倒序渲染像素哈希一致；元素不越安全区、不横向溢出、主画面不进字幕带；倒计时回归经过 01:00 → 00:59。

## 人工看片
- [ ] 每拍只有一个主动画，其他元素安静。
- [ ] 主画面没有重复字幕整句。
- [ ] 承接自然：旧元素缩成角标 / 让位，没有硬切。
- [ ] 数字落地后停住，不抖、不跳宽度。
- [ ] 风格只用一个 Style Lock；Logo / 片尾 / 声线来自项目配置。
- [ ] 示例数据在画面或字幕里标注"示例 / 假设"。
