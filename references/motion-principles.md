# 动作原则

## 时长（30fps）
- 词组入场 8–12 帧，词组间隔 4–8 帧（约跟语速）。
- 关键词荧光：词落定后 3–6 帧开始，10–14 帧扫完。
- 计数：1.2–2 秒，ease-out（outExpo）减速落地；落地后 8 帧轻微 settle。
- 时钟：线性走时；每秒只在最后 ~35% 时间里滚动变化的位。
- 搬运 / 让位：15–22 帧，inOut；搬运可加 40–80px 弧线。
- 箭头：18–26 帧，到达前 4 帧出箭头。
- 勾选：10 帧，对准"做完 / 完成"那个字。

## 缓动
- 入场用 ease-out（快进慢停），退场用 ease-in，位移用 inOut。
- outBack 只给小元素的 pop，避免数字和长文本过冲。
- 时间分离：先算 progress（何时、多快），再映射到属性（是什么）。

## 承接（连续构图）
- 同一信息在画面里只出现一次：它可以变大、变小、移动，但不复制。
- 每拍结束写清 `then`：缩成角标（chip）/ 上移让位 / 搬到新版位 / 退场。
- 锚点：标题或主题词在全片保持在固定位置，作为观众的"地图"。

## seek-safe
- 所有值都是 `f(frame)`；没有累加状态、没有 CSS 动画、没有随机数和当前时间。
- 噪声/抖动用固定 seed（RoughDefs 的 feTurbulence seed=7）。
