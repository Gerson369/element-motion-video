# 手写笔记 handnote

## Use when
生活方法、效率、学习、个人成长；想要"有人在本子上边讲边画"的亲近感。

## Style Lock
### Background
暖白纸 #FBF7EE，无纹理或极淡纸纹；不放插画背景。
### Layout
左对齐为主；标题锚点在顶部；主画面一次一个主元素，大留白。
### Color
墨色 #2B2A28 + 一个强调色（朱红 #E0533D）+ 荧光黄底（关键词）。
### Typography
Noto Sans SC 粗体；数字同字体等宽数字。
### Components
荧光笔扫底、手绘抖动线条（RoughDefs）、圆角勾选框、细箭头。
### Text density
主画面 ≤ 12 字；其余交给字幕。
### Negative constraints
不用渐变、不用投影堆叠、不用 3 种以上颜色、不用卡通贴纸。
