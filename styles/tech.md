# 科技风 tech

## Use when
AI、软件、数据产品、科技趋势。

## Style Lock
### Background
深蓝黑 #0B1020，纯色。
### Layout
居中或左对齐；数字与图解是主角。
### Color
浅字 #EAF0FF + 一个青色强调 #3DE0C5（线条、进度、关键数字）。
### Typography
Noto Sans SC；等宽数字。
### Components
细线箭头、圆角暗色卡片、发光感只用低透明度底色，不用真正的 glow 滤镜。
### Text density
主画面 ≤ 10 字。
### Negative constraints
不用赛博霓虹多色、不用扫描线和噪点乱闪、不用 HUD 堆叠。
