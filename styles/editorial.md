# 简洁编辑风 editorial

## Use when
观点、商业、新闻解读、数据说明；需要可信、克制、像杂志版面。

## Style Lock
### Background
纯白 #FFFFFF。
### Layout
强网格、左对齐、细分隔线；数字可做大标题。
### Color
黑 #111 + 一个专色（报红 #C8102E），专色只给关键数字和高亮。
### Typography
Noto Serif CJK SC（衬线）标题与数字。
### Components
直线箭头、方角卡片、细描边进度条；不加抖动。
### Text density
主画面 ≤ 12 字；标题可两行。
### Negative constraints
不用荧光、不用圆润卡通、不用发光效果。
